# Changelog

## 0.1.0 · Research preview · 2026-10-26

- Evidence records with immutable persistence, falsifiable analytical hypotheses and independent confirmation gates.
- Prepared NVIDIA CUDA/Triton path for reductions, softmax, layer normalization and fused elementwise inference.
- Actual CPU control suite, fitted intervention selector, family/shape holdouts, random/rule/Bayesian replay baselines and context/uncertainty ablations.
- Static KERNELDARWIN LAB with eight views, local import, measurement charts, unavailable-evidence states and export.
- CLI/API, regression comparison, gated callable export, optional profiler traces and sanitizer/application procedures.
- Documentation, prior-art/licensing review, automated CPU CI and a manual self-hosted CUDA validation workflow.

CUDA kernels have not been compiled or executed on the Apple M4 development host. GPU performance, GPU policy benefit, causal diagnosis, sanitizer passes and the application benchmark remain unvalidated. This preview does not satisfy the full research objective's GPU evidence requirements.
