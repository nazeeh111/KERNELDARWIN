# Changelog

## 0.3.0 · Workload numerical preview · Unreleased

- Added a usable local cosine-search application, typed MLX APIs and `kd workload doctor`, `demo`, `search` and gated `export` commands. The default path uses the complete compiled stable query.
- Executed four authored stable-normalization configurations and two fused query-score configurations on an Apple M4. Independent numerical suites passed 16 row/application/guard tests and seven fused GPU test methods, with Metal API and GPU validation enabled.
- Implemented exact input rules, source/application/baseline/study/runtime identities, immutable source snapshots, explicit dtype/shape/layout semantics, finite validation, failed-refresh rollback and library fallback.
- Completed a frozen first-target study with matched fixed/per-shape/joint search data, three independent sessions and 24 fresh-process starts. It failed application confirmation; no optimized artifact or acceleration claim was accepted.
- Investigated fused query normalization/scoring as the second bounded target. Numerical and installed changed-input checks passed; an unstable identical-baseline study stopped before tuning. Failed evidence is preserved.
- Added a static Workload interface, semantic and installation guides, editable architecture, complete negative results and an unsent launch draft. Final browser/package/release verification remains pending.
- Preserved the original CPU records, v0.1/v0.2 releases and media. Actual Metal execution does not validate the prepared CUDA/Triton path.

## 0.2.0 · Investigation workbench · 2026-10-26

- Rebuilt the LAB around the measured experiment: latency fingerprint, matched-pair inspection, linked candidate selection, and a compact verification rail.
- Added self-hosted IBM Plex typography, a purpose-built dark instrument system, readable source comparison, parent-aware lineage groups, and accessible responsive navigation.
- Split the frontend into controller, validation, pure data transforms, charts, lineage, views, DOM primitives, and reduced-motion-aware animation modules.
- Hardened malformed-import handling, nonwinner sample pairing, large trace imports, source identity display, keyboard focus, and trace truncation disclosure.
- Added frontend unit regressions and reproducible Playwright browser CI. Recorded experiment bytes and GPU validation limits are unchanged.
- Previous release and demo remain available as v0.1 artifacts. This UI release makes no new CUDA performance claim.

## 0.1.0 · Research preview · 2026-10-26

- Evidence records with immutable persistence, falsifiable analytical hypotheses and independent confirmation gates.
- Prepared NVIDIA CUDA/Triton path for reductions, softmax, layer normalization and fused elementwise inference.
- Actual CPU control suite, fitted intervention selector, family/shape holdouts, random/rule/Bayesian replay baselines and context/uncertainty ablations.
- Static KERNELDARWIN LAB with eight views, local import, measurement charts, unavailable-evidence states and export.
- CLI/API, regression comparison, gated callable export, optional profiler traces and sanitizer/application procedures.
- Documentation, prior-art/licensing review, automated CPU CI and a manual self-hosted CUDA validation workflow.

CUDA kernels have not been compiled or executed on the Apple M4 development host. GPU performance, GPU policy benefit, causal diagnosis, sanitizer passes and the application benchmark remain unvalidated. This preview does not satisfy the full research objective's GPU evidence requirements.
